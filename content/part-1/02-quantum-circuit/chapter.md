# 量子电路入门：门、线路图与测量

你翻前面的示例，会看到一堆调用：`qc.h(0)`、`qc.cx(0,1)`、`qc.measure_all()`。这些是什么？为什么把 `h` 叫"哈达玛门"、"把两根线连起来"就是"纠缠"？这一章把**量子电路**这个"量子程序的样子"一次讲透。

> 一句话直觉：**量子电路 = 一根根时间线（量子比特）从左边画到右边，上面一个接一个地"贴"量子门（操作），最后拿"测量"读出结果。** 就像一张流水线图纸：比特是工件，门是工位，测量是质检出口。

## 三个零件：比特、门、测量

### 量子比特（qubit）：画成一根横线

经典电路画 0/1 的电平线；量子电路画**时间线**，从左到右就是时间流逝的方向。一根线 = 一个 qubit，初始都是 `|0⟩`。

```
q0: ──────────────
q1: ──────────────
```

### 量子门（gate）：画成贴在线上的方块

把 qubit 的状态"改一下"的操作就是门。你已经在示例里用过的两个最基本的门：

- **哈达玛门 `H`**（方块一个 H）：制造叠加。把确定态压成"一半 0 一半 1"的模糊态。
- **CNOT 门 `cx`**（跨两根线的 `•──⊕`）：制造纠缠。**当控制位是 1 时，翻转目标位**。它是把两个 qubit"焊"在一起的胶水。

```
q0: ──H──•──
         │
q1: ─────⊕──
```

上面这张图就是上一节那个"Bell 态"电路：先对 q0 过 H 进入叠加，再用 CNOT 把 q1 焊上 → 两根线从此"共享命运"。

### 测量（measure）：画成读数仪表

线的终点是测量，把叠加随机坍缩成一个确定的 `0/1` 并被记录进**经典寄存器**。只有到这步，你才"看见"结果；之前一切都是概率云。

## 为什么电路是有方向的

量子门**必须从左到右按顺序执行**，不能逆着时间跑。这就是为什么线路图用"时间线"而不是"方框图"——**顺序即逻辑**。某个门作用在哪些比特上（接口），由它在哪个方块挂在哪根线上决定。

```
   时间 →→→→→→→→→→→→→→→→→
q0: ──H──●─────────────
         │
q1: ─────X───M──────────  (M = 测量)
```

> 读图口诀：**从上到下是"哪些比特"，从左到右是"先后顺序"，方块是"操作"，最右是"读出"。**

## 经典电路 vs 量子电路：三点关键区别

| | 经典电路 | 量子电路 |
|---|---------|---------|
| 状态 | 确定的 0/1 | 可叠加（`α|0⟩+β|1⟩`的概率幅） |
| 操作 | 与非门等，翻转确定结果 | 门可产生叠加/纠缠，改变概率分布 |
| 读出 | 读多少遍都一样 | 测量即坍缩，读一次就破坏原态 |

> 第二条尤其关键：经典门是不可逆/确定性的改写，量子门大多**可逆且只改变概率幅**——这决定了"量子并行"和"纠缠/测量"这些经典里没有的东西。

## 从电路到程序

你用 Qiskit 写 `qc.h(0)` 时，就是在**往这张图纸上贴一个 H 方块**；`qc.cx(0,1)` 就是画那根带 `•──⊕` 的连接桥；`qc.measure_all()` 就是在每条时间线终点装测量仪。**电路图就是程序，程序就是电路图**——两者完全一一对应。

> 打开右侧代码：我们用 Qiskit 搭一件真实的迷你电路（H + CNOT + 测量），并把**它画成一张 ASCII 电路图**打印出来——你会在黑框里看到我上面讲的"时间线 / 门方块 / 测量仪表"真实地排布出来，然后跑几百次，看纠缠态 `00/11` 五五开。亲手看懂这张图，后面 Grover / Shor 那些复杂线路就都只是"更多方块拼在一张图"。

## 边界提示

本章只介绍"怎么读电路图"，不深入每个门背后的量子力学矩阵。你只需建立三个固定点：**比特=线、门=方块、测量=终点仪表**。真正的难点（如测量基、相位、oracle）在后面各篇用到时再用直觉补充。有了这张"电路世界观"，第 2 篇 Grover 的 oracle、第 4 篇 BB84 的编码基，都会顺理成章。
