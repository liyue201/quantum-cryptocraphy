# 叠加、测量坍缩与纠缠：量子的三张底牌

上一节我们用一颗量子比特尝到了"叠加"的滋味。但单比特只是开胃菜，密码学真正关心的是**多比特在一起**时产生的两个怪癖——这让量子体系区别于任何经典系统：

1. **测量坍缩**：不看它时，状态是"叠加"；你一测量，就随机坍缩成一个确定值，**而且坍缩不可逆**。
2. **纠缠**：两个比特共享同一个"命运"——对其中一个的测量，立刻决定另一个的值，哪怕它们相距再远。

> 这两点，一个是"隐私的源头"，一个是"不可克隆 / 不可窃听"的源头。量子密钥分发（QKD，后续第 5 篇）命根子就埋在第二点里。

## 实验一：测量坍缩（不可逆的随机抽取）

经典比特你随时可以"看"，看完它还是原来那个值。量子比特**不行**——测量本身会改变它。

> 右侧代码第一段：让两个比特都过一遍哈达玛门进入叠加，然后**测量 100 次并统计**。
> 你会看到四种结果 `00/01/10/11` 大致各占四分之一——因为两颗比特的叠加态连成了一个均匀的"四选一"盒子。每一次测量都是一次**真正不可逆的随机抽取**。

### 停一下：为什么输出里"概率"和"统计"是两段？

细看右侧代码，你会发现它调用了两个函数：`show_state`（打印"测量前状态概率"）和 `sample`（打印"测量 N 次统计"）。这不是重复，而是量子力学里最该分清的两件事——**"算概率"和"去测量"是两码事**。

- **`show_state` 只推演、不测量。** 它用 `Statevector.from_int(0, 2 ** n).evolve(circ)` 这行：从"全是 0"的起点（也就是 `|00…0⟩`）出发，把电路里所有门按顺序"跑一遍"，得到一个状态向量 `sv`。这个 `sv` 同时装着 `00、01、10、11` 各自的振幅，`|振幅|²` 就是概率。但到这里为止，探测器**并没有落地**——它是在问"**如果不测量，理论上该是什么概率分布？**"。
- **`sample` 才真正测量。** 它先 `measure_all()` 加测量仪表，再用 `AerSimulator().run(shots=…)` 跑很多次，每次运行都让状态**坍缩**成一个确定结果，最后统计每个结果出现的次数。

打个比方：`show_state` 像是把骰子在空中晃了无数下，看着每个面**理论上**都是 `1/6`；`sample` 才是让骰子**真的落下**，数一数 256 次里每个面出现几回。前者精确、后者随机——这正是量子模拟里"推演"与"测量"的分工。只有在 `measure` 出现时，叠加态才会坍缩；`evolve` 只推演、不坍缩。看到"只有概率、没看到测"时不是漏了代码，而是故意停在"测量前"。

## 实验二：纠缠（共享同一个命运）

现在在两根都叠加的比特之间，加一个 **CNOT 门**。它会"当第 1 根是 1 时，把第 2 根翻转"。结果：两根进制线被"焊"在一起——这就是 **Bell 态 / 纠缠态**。

> 右侧代码第二段，同样测量 100 次并统计。神奇的事情发生了：
> 结果**只可能**是 `00` 或 `11`，**永远不可能**是 `01` 或 `10`。
> 也就是说：你测第 1 根得到 `0`，第 2 根**必定**也是 `0`；得到 `1` 就必定是 `1`。

### 为什么这里"同向"而不是"相反"？

你可能想问：凭什么输出是 `00 / 11`（一样），而不是 `01 / 10`（相反）？答案藏在构造里——**纠缠的"方向"由门的搭法决定，同向和反向都是纠缠，只是这版代码恰好做了同向**。它靠三行搭出来：

```python
qc.h(0)      # 第 0 根先进入叠加
qc.h(1)      # 第 1 根也进入叠加
qc.cx(0, 1)  # CNOT：控制线=第 0 根，目标线=第 1 根
```

CNOT 的规则是：**当控制线为 1 时，翻转目标线；控制线为 0 时，目标线不动。** 现在控制线（第 0 根）自己也在叠加，于是：

- 第 0 根会"随机塌到 `0` 或 `1`"。
- 塌到 `0` → 控制线为 0 → CNOT 不动作 → 第 1 根保持原样，随它同为 `0`。
- 塌到 `1` → 控制线为 1 → CNOT 翻转目标线 → 第 1 根被迫跟着成为 `1`。

两条线"你定 0 我就 0、你定 1 我就 1"，**控制线决定目标线**，表现出来自然就是同向的 `00 / 11`。

**那方向由什么决定？** 完全由怎么搭门定。只要改一下，就能得到"相反"的纠缠：先把第 1 根换成"塌到 1 才反应"，比如

```python
qc.h(0)
qc.x(1)     # 给第 1 根反一下，让它默认表达相反
qc.cx(0, 1)
```

输出就会变成 `01 / 10`（第 1 根总是第 0 根的**反**）。而这**同样是纠缠**——关键词从来不是"同向/反向"，而是"测量一个，立刻锁定另一个"。

## 为什么纠缠对密码学是"宝贝"

这看着像"两个硬币必须同时同面"，似乎是古典概率。但区别在**时机**：

- 经典：两颗硬币事前（按某种分布）就已决定了正反，只是你不知道。
- 量子：**在你测量之前，它们并没有确定的正反**；你的测量"当场创作"了结果，且两块瞬时一致。

这带来一个密码学上千金不换的性质——**一对无法预先伪造、又天然相关的随机数**。攻方无法知道也**无法偷看**而不被发现（一偷看就坍缩、就穿帮）。这就是后面 BB84 协议能实现"量子一把钥匙，窃听必被识破"的根基。

```
测量坍缩  → 结果不可逆、真正随机
纠缠相关  → 两块永远一致、且不可偷看
→ 合起来 = 一条"安全、可验证、防窃听"的密钥候选
```

## 边界提示

本节演示了纠缠的**相关性**，但还没到它能防窃听的全部秘密（那需要"测量基"的概念，见 QKD 那篇）。另外：纠缠的相关性是**瞬时相关**，但它**不能用来超光速传信息**（爱因斯坦的"幽灵"，物理定律已证明通信速度依然受限）。不要误解成"量子可以瞬间跨星球发消息"。
