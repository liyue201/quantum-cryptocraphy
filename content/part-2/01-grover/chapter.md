# Grover 搜索：把暴力穷举变成平方根

上一节你见过叠加和纠缠这对"宝贝"。现在让它们干活。密码学里最常见的攻击姿势是**穷举**：钥匙不知道，就把所有可能一个个试。经典世界，试 N 个候选平均要试 N/2 次；**Grover 算法把这变成约 √N 次**。这就是为什么量子能威胁哈希、助记词、地址这类"暴力搜索"型防线。

> 别被名字吓到。Grover 其实讲了一个很直观的道理：**用量子叠加，一次就能"同时问"很多候选；再用一组为"放大"设计的操作，把正确答案的概率从 1/N 抬到接近 1。** 好比从一个 10000 人的班级里找 Ta——经典是挨个问，Grover 是"用一面能折射名字的镜子，每次把能量往 Ta 身上聚拢一点"。

## 搜索 vs 分解：两种完全不同的威胁

理解 Grover 前，先分清它和 Shor（下一节）的分工：

- **Shor**：专门撬 RSA/ECDSA 的数学结构（大数分解、离散对数）——**结构性的、致命的**。
- **Grover**：不挑数学结构，它是一种**通用搜索加速器**——只要"猜中就是赢"的黑盒问题，它都能从 N 提速到 √N。哈希碰撞、暴力搜私钥都能沾光。

> 关键认知：Grover 的攻击效果只是**平方根加速**，不等于秒破。它的真正危险在于减少密钥/哈希所需的**安全位长**（**安全强度**：衡量"攻破需要的计算量"，比如 2^128 次运算=128 位安全强度，越大越安全）——例如 128 位安全性在 Grover 下等价于只有 64 位。所以**应对 Grover 的办法通常是把参数翻倍**，而不是推翻整个算法。

## 三块的剧情：oracle → 均匀叠加 → 扩散放大

Grover 一集就三个角色：

1. **Oracle（预言机）**：一个黑盒函数，对"答案候选"回答 `1`，对其他全部回答 `0`。它把"这是不是答案"的标记刻进叠加态。
2. **均匀叠加**：开场把所有候选态铺成一边高的叠加态（几颗比特同时过哈达玛门）。
3. **扩散操作（Amplitude Amplification）**：围绕"平均值"做一次翻转反射，让带标记态的概率幅度升高、其他降低。**重复多次**，标记态概率被一轮轮"聚光"，测量时几乎必中。

> 打开右侧代码：我们做一个 2 颗量子比特的搜索，目标是把 `11` 标记出来。代码一步步：铺叠加 → 挂 oracle → 扩散放大 → 测量，最后直出统计直方图——你会看到 `11` 的概率被从 1/4 抬到接近 1。

## 为什么"√N"很值钱

直觉上会有人说"不就是少了一半个零吗？" 但平方根在指数面前意义重大：

- **哈希/地址暴力**：经典搜 `2^n`，Grover 变 `2^(n/2)`。原来 128 位强度的东西，现在按 64 位强度防。
- **对策很简单**：把参数翻倍（密钥/哈希加长）即可抵消。这也是为什么 *哈希类*防线的主要应对是"加长"，而不必放弃算法。

```
攻击 N 个候选：
  经典   →  ~N/2     次试图
  Grover →  ~√N      次试图
→ 等价于把安全位长减半，对策 = 参数翻倍
```

## 边界提示

Grover 威胁的是"搜得到就算赢"的问题（穷举、碰撞、密钥爆破）；它是**多项式级平方根加速**，不推翻数学结构本身。真正把 RSA/ECDSA 一键送进墓地的，是下一节 **Shor 分解**。两者叠加在中本聪明的密码体系里：哈希/地址怕 Grover，签名（ECDSA）怕 Shor——这正是后面「量子计算对加密货币的冲击与防护」那一章要拆解的完整剧情。
