# 为什么量子会颠覆今天的密码

你现在的密码学，靠的都是**"数学难题"**：RSA 依赖大整数分解很难，ECDSA 依赖离散对数很难。量子计算机之所以恐怖，不是"算得快"，而是它**换了一种算法，让这些难题变得不难**。

> 忘了量子；先想清楚我们的痛点：**一台够强的量子机，能把你今天私钥对应的公钥，反向"硬算出"私钥。** 这不是未来时，是"窃取后解密（harvest now, decrypt later）"的现在进行时——攻击者今天就把你的密文/公钥囤起来，等机器成熟再批量破解。

## 先补一个量子直觉：叠加态

经典比特只能是 `0` 或 `1`。而一个**量子比特**可以同时是 `0` **和** `1` 的"混合"，直到被**测量**的一瞬间才随机"坍缩"成其一。这就是**叠加态**。

> 打开右侧代码，第一块先看"一根干净的量子比特"：测 10000 次，永远得到 `0`。
> 现在把 `h(q[0])`（哈达玛门）那一行**取消注释再跑**：它把比特推进"一半 0、一半 1"的叠加态，测下来大约五五开——这不是"假随机"，这就是量子叠加的直接证据。

## 为什么"叠加"能威胁密码

单个比特叠加看不出威力。厉害的是比特**之间有纠缠、能并行叠加**——这给了 Shor/Grover 算法撬动数学难题的杠杆。现在你只需记住：

- **Grover** 让"在 N 个候选中找钥匙"从 N 次降到 √N 次 → 威胁哈希（如暴力搜地址）；
- **Shor** 把"因数分解/离散对数"从指数级降到多项式级 → 直接把 RSA、ECDSA 判死刑。

具体算法后面各篇展开，本节只要形成一条认知主线：

```
经典密码的"护城河" = 高中数学很难
量子计算机        = 把"很难"变成"不难"
```

## 边界提示

本节只建立了"量子威胁"的直觉，代码演示的是**单个量子比特的叠加**，还不是破解算法（那需要多比特纠缠，见第 1、2 篇）。范式的转变点：**安全不再来自"算得慢"，而要另找数学的支点**——这正是后量子密码（第 3、4 篇）和量子密钥分发 QKD（第 5 篇）要做的事。
