# 前言：写给即将算明白的你

## 为什么值得读

你每天都在使用密码——登录、转账、扫码、订阅。但绝大多数使用者并不知道这些"锁"长什么样，更不知道**它们正面临一场由量子计算挑起的百年不遇的"换锁潮"**。

这本书想带你把量子密码学"算明白"：

- **每一套加密、每一张签名、每一次密钥交换**，背后都站着一小段数学和一个具体的困难假设。读懂了它，你就从"听说过量子危机会破解 RSA"变成"想清楚：为什么偏偏是 RSA 会被破、而格密码和哈希却暂时安然无恙"。
- 全书按**认知递进**组织：先认识量子威胁（第 0 篇）→ 再学叠加、纠缠等量子地基（第 1 篇）→ 见识 Grover 与 Shor 这些攻击武器（第 2 篇）→ 换上后量子铠甲 PQC（第 3 篇）→ 打开天生防窃听的 QKD（第 4 篇）→ 最后动手搭建一套抗量子迷你体系（第 5 篇）。**前一篇总是后一篇的垫脚石。**
- **每一个可运行示例都刻意保持"短小到能一次读懂"**——点右侧「▶ 运行」就能亲眼看它跑起来，还能随手改代码验证你的猜想。错误与调试，正是深度理解的第一步。

## 你能从这里带走什么

| 章节 | 你将掌握的核心直觉 |
|------|--------------------|
| 第 0 篇 | 量子威胁从何而来：为什么今天的 RSA/ECDSA 终将失效 |
| 第 1 篇 | 叠加、测量坍缩、纠缠——量子加密的物理地基 |
| 第 2 篇 | Grover（搜索）与 Shor（分解）怎么撬开经典密码，对加密货币的冲击与防护 |
| 第 3 篇 | 后量子 PQC：哈希签名、LWE/格、Kyber/Dilithium 与选型地图 |
| 第 4 篇 | 量子密钥分发 QKD：BB84 如何用坍缩机制抓窃听 |
| 第 5 篇 | 综合实战：混合加密 TLS、一颗加密的"量子信" |

## 给谁看？需要什么前置？

- **面向"无量子与密码学基础的程序员"**：有编程经验、能读懂行业里"密钥、签名、哈希、加密"这些词，但没有量子力学或密码学修练背景。
- **理想的前置**只是基本的数学直觉（加减乘除、函数、一点点概率），本书会随用随讲，不预设高等数学门槛。
- 量子计算部分我们用**直觉 + 可运行示例**来讲，不堆砌艰深推导；想深究数学内在乐趣的读者，可再顺章节末尾的提示自行延伸。

## 一点学习建议

不必从头到尾一遍读完。**挑你手头正在做的事来读**——比如你在做加密传输，就跳到第 4 篇 QKD 或第 5 篇混合加密；你在接触钱包/签名，就从第 3 篇哈希签名读起。右栏示例的"改写"是你最好的老师：**把常数改一改、把噪声调一调、把窃听开关拨一下**，看看输出如何剧变——这比任何文字更能建立直觉。

准备好了吗？我们从头开始：**先看清那个一步步逼近的量子威胁。**
