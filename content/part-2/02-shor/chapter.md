# Shor 分解：如何瞬间破解 RSA

RSA 的安全建立在"把一个大数分解成两个质数，很难"。比如给 N = 15，谁都能算 3×5；但给一个 2048 位的大数，经典计算机穷举加暴力也要几亿年。**Shor 算法偏偏找到一条"周期"捷径，把它变成几分钟能干完的事**——这正是"量子把难变不难"最经典的一战。

> 忘了那些复杂的数学符号，先抓一个直觉：**RSA 的"密码锁"其实藏着一个隐藏的周期性结构，经典计算机看不见，量子计算机用相位估计一眼就能看见。** 一旦看见周期，分解就像拆弹抓到了那根线。

## 关键一步：把"分解"翻译成"找周期"

Shor 的精妙之处:它不直接分解 N，而是**把分解问题变成一个"找函数周期"的问题**，然后再用一个叫 **相位估计（QPE）** 的量子工具去量周期。数学上这一步叫"order finding"：

1. 随便取一个小子 g（和 N 互质）。
2. 求最小的正整数 r，使得 `g^r ≡ 1 (mod N)`。这个 r 就叫 **order**。
3. 只要 r 是偶数，且 `g^(r/2) != -1 (mod N)`，那么 `gcd(g^(r/2)+1, N)` 和 `gcd(g^(r/2)-1, N)` 就是 N 的两个因子。

> 为什么？因为 `g^r - 1 = (g^(r/2)-1)(g^(r/2)+1)`，而 N 整除左边却不整除其中任何一个时，公共因子就是 `gcd` 算出来的那个——它必然是 N 的真因子。

## 经典 order finding 有多慢，量子就有多快

- **经典**：得靠反复乘除和试凑，没有捷径，复杂度指数级。
- **量子（QPE）**：在一个叠加态上"并行"试所有候选指数，用相位估计算出 r——复杂度是**多项式级**，即时间随 N 的位数只按多项式增长，而不是指数爆炸。

> 打开右侧代码：我们用一个**经典模拟的 order finding** 来演示这条"路线图"——对 N = 15 和若干随机 g，枚举出 r，再用 r 套出因子。你能亲眼看到：先用一个很简单的试探就拿到 order，再一步 `gcd` 就解出 3 和 5。代码还会对比：如果 g 碰巧给出奇数 order 或退化情况，就换一个 g 重来（真实 Shor 同样会重试几次）。

## 这打击面有多大

RSA 两头都挨刀：

- 大数分解被 Shor 降维打击 → **RSA 判死刑**。
- 同样的周期性工具也破解**离散对数** → **ECDSA / Schnorr 签名的私钥也保不住**。

这直接牵连今天的**加密货币签名为安全性**：比特币/以太坊的地址都是用 ECDSA/Schnorr 签名的，Shor 能从一个已知公钥反推私钥。所以"量子威胁数字货币"不是科幻，是一条具体到算法的攻击链——下一章我们会专门拆解它。

```
Shor 三步走：
  ① 选随机 g，与 N 互质
  ② order finding：求最小 r 使 g^r ≡ 1 (mod N)   ← 量子相位估计在这里提速
  ③ 若 r 为偶数且 g^(r/2) ≠ ±1：gcd(g^(r/2)±1, N) 得到因子
→ RSA / ECDSA 的数学结构，从此不再是护城河的支点
```

## 边界提示

本章演示的是 Shor 的**数学骨架**（order finding → 因子），用 Python 经典模拟来直观呈现；真实的量子加速在于用相位估计算法求 order，那部分需要多量子比特的线路与逆傅里叶变换，超出本章范围。你只要记住一条主线：**Shor 把 RSA/ECDSA 赖以生存的"指数级困难"降到了"多项式级简单"**。这正是下一章量化"加密货币受冲击程度、怎么防"的第一块基石。
